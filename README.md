# Smartlog CS Calculator

스마트로그 CS 전용 계산기입니다.

## 파일 구조

- `index.html` — 화면 구조
- `styles.css` — UI 스타일
- `app.js` — 계산 로직 및 인터랙션

## Netlify 배포

세 파일을 GitHub 저장소의 최상위 경로에 함께 올리면 됩니다.
Netlify는 `index.html`을 시작 페이지로 사용합니다.

## 유지보수

- 화면 구성/문구 수정 → `index.html`
- 디자인/반응형 수정 → `styles.css`
- 요금/계산식/버튼 동작 수정 → `app.js`
